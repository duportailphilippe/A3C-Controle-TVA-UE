**Dernière mise à jour : 7 septembre 2026**

## 1. Objet

Contrôle TVA UE — VIES est un outil d’assistance destiné à faciliter la vérification, l’identification et la documentation de partenaires économiques.

Il peut notamment permettre :

- la vérification d’un numéro de TVA intracommunautaire via VIES ;
- l’identification d’entreprises ;
- la consultation de sources publiques ;
- la documentation de contrôles EORI lorsque cette fonction est disponible ;
- la génération de preuves de diligence ;
- le suivi et le recontrôle de partenaires.

## 6. Interprétation des résultats

Les informations retournées par l’extension doivent être appréciées dans leur contexte.

En particulier :

- une TVA valide constitue le résultat retourné par VIES au moment de la consultation ;
- une TVA non reconnue comme valide ne signifie pas nécessairement que l’entreprise n’existe pas ;
- une indisponibilité technique ne doit pas être assimilée à un résultat négatif ;
- un résultat EORI est distinct d’un résultat TVA ;
- la richesse documentaire disponible ne constitue pas une note de solvabilité ou de risque.
