# Contrôle TVA UE — VIES

### Extension Google Chrome développée par A3C

**Vérifiez. Identifiez. Documentez.**

**Contrôle TVA UE — VIES** est une extension Google Chrome développée par **A3C Expert Comptable à Dunkerque** pour faciliter l'identification, le contrôle et la documentation des partenaires économiques français et européens.

L'extension s'appuie notamment sur le système européen **VIES** pour contrôler les numéros de TVA intracommunautaire et complète progressivement cette vérification par différentes sources publiques françaises et européennes.

## 🎯 À quoi sert l'extension ?

Une relation commerciale commence souvent avec seulement quelques informations :

- un nom d'entreprise ;
- un SIREN ou un SIRET ;
- un numéro RCS ;
- un numéro de TVA intracommunautaire ;
- un identifiant d'entreprise européen.

L'objectif de l'extension est de faciliter les premières diligences permettant de répondre à une question essentielle :

> **Avec qui sommes-nous réellement en train de travailler ?**

---

## 🔎 Principales fonctionnalités

Selon le pays et les informations disponibles, l'extension permet notamment :

- le contrôle des numéros de TVA intracommunautaire via **VIES** ;
- la reconnaissance des **SIREN, SIRET et RCS** ;
- la reconnaissance de différents identifiants d'entreprises européens ;
- l'identification d'entreprises françaises et européennes ;
- le contrôle ou la proposition d'identifiants **EORI** lorsque cela est possible ;
- la récupération d'informations juridiques et économiques publiques ;
- la consultation de différentes sources officielles ;
- la génération d'une **preuve PDF de diligence** ;
- la conservation d'un historique des contrôles ;
- la comparaison entre plusieurs contrôles successifs ;
- la constitution d'un portefeuille de partenaires ;
- le recontrôle de plusieurs entreprises ;
- le traitement de fichiers CSV pour certains contrôles en masse ;
- la consultation de données complémentaires telles que **LEI / GLEIF** lorsqu'elles sont disponibles.

Les données accessibles et leur niveau de richesse varient selon les États membres et les sources publiques disponibles.

---

## 🇪🇺 Les 27 États membres de l'Union européenne

L'architecture de contrôle VIES couvre les **27 États membres de l'Union européenne**.

La richesse documentaire n'est toutefois pas uniforme.

Chaque État dispose de ses propres :

- registres ;
- identifiants ;
- formats juridiques ;
- politiques Open Data ;
- modalités d'accès aux informations publiques.

L'extension ne cherche donc pas à fabriquer artificiellement une information uniforme.

> **Elle restitue ce que les sources disponibles permettent réellement de documenter et signale leurs limites.**

---

## 🧾 VIES : VALIDE, NON VALIDE ou INDISPONIBLE

L'extension distingue volontairement plusieurs situations.

### ✅ VALIDE

Le numéro est reconnu comme valide par VIES au moment de la consultation.

### ❌ NON VALIDE

Le numéro n'est pas reconnu comme valide par VIES au moment de la consultation.

Cela ne signifie pas nécessairement que l'entreprise n'existe pas.

### ⚠️ INDISPONIBLE / ERREUR TECHNIQUE

Le service VIES ou la base nationale interrogée n'a pas permis d'obtenir un verdict exploitable.

**Une indisponibilité technique n'est jamais transformée artificiellement en résultat « TVA non valide ».**

---

## 📄 Preuve de diligence

L'utilisateur peut générer une preuve PDF reprenant notamment :

- le résultat du contrôle VIES ;
- la date et l'heure de la consultation ;
- l'identité obtenue ;
- les références techniques disponibles ;
- les informations publiques complémentaires ;
- les sources consultées ;
- l'éventuel contrôle EORI ;
- différents éléments utiles à la documentation du dossier.

Cette preuve constitue une :

> **photographie datée des diligences effectuées**

Elle ne constitue ni :

- un certificat délivré par l'administration fiscale ;
- une garantie de solvabilité ;
- une certification de l'entreprise contrôlée ;
- une signature électronique qualifiée.

---

## 🔄 Suivi des partenaires

L'extension ne se limite plus à un contrôle ponctuel.

Elle permet progressivement de documenter une logique de suivi :

**Partenaire → contrôle → ancienneté → recontrôle → évolution**

Un portefeuille de partenaires peut ainsi être constitué afin de faciliter les diligences périodiques.

Une source temporairement indisponible n'est pas automatiquement interprétée comme un changement de situation de l'entreprise.

---

## 📊 Contrôles en masse

Pour les professionnels devant contrôler plusieurs partenaires, l'extension comporte également des fonctions de traitement en masse, notamment à partir de fichiers CSV.

Le moteur distingue toujours :

- un véritable verdict VIES ;
- une indisponibilité temporaire ;
- une erreur technique ;
- une réponse inexploitable.

L'objectif est d'éviter qu'une indisponibilité d'un État ou une saturation du service ne produise artificiellement une série de résultats « non valides ».

---

## 🛡️ Une aide à la diligence, pas un automate de décision

L'extension fournit des informations et facilite leur documentation.

Elle ne décide pas si une entreprise doit ou non entrer en relation avec un partenaire.

Elle ne remplace pas :

- le jugement professionnel ;
- les diligences complémentaires rendues nécessaires par une situation particulière ;
- une procédure complète de connaissance client ou fournisseur ;
- une procédure complète LCB-FT / KYC ;
- l'identification complète des bénéficiaires effectifs ;
- l'analyse des PPE / PEP lorsqu'elle est nécessaire ;
- la consultation directe d'une source officielle lorsqu'elle est requise.

> **L'outil fournit l'information ; le professionnel ou le dirigeant conserve la décision.**

# 💻 Installation dans Google Chrome

L'extension est actuellement distribuée sous forme locale dans l'attente de sa diffusion via le Chrome Web Store.

## 1 — Télécharger

Téléchargez la dernière version :

### [📦 Extension-Chrome-A3C.zip](https://github.com/duportailphilippe/A3C-Controle-TVA-UE/releases/latest/download/Extension-Chrome-A3C.zip)

---

## 2 — Décompresser

Décompressez complètement l'archive dans un dossier permanent, par exemple :

`C:\A3C\Controle-TVA-UE\`

**Ne chargez pas directement le fichier ZIP dans Chrome.**

---

## 3 — Ouvrir la gestion des extensions

Dans Google Chrome, saisissez dans la barre d'adresse :

`chrome://extensions/`

---

## 4 — Activer le mode développeur

Activez :

**Mode développeur**

---

## 5 — Charger l'extension

Cliquez sur :

**Charger l'extension non empaquetée**

Sélectionnez ensuite le dossier décompressé contenant directement le fichier :

`manifest.json`

---

## 6 — Vérifier l'installation

Vérifiez que :

**Contrôle TVA UE — VIES**

apparaît sans erreur.

Contrôlez également le numéro de version affiché par Chrome.

Vous pouvez ensuite épingler l'extension dans la barre d'outils.

## 🔐 Confidentialité et maîtrise par l'utilisateur

L'extension est conçue selon un principe de maîtrise par l'utilisateur.

La détection d'un identifiant présent sur une page Web ne déclenche pas automatiquement une interrogation VIES.

Lorsqu'un mécanisme utilisant le presse-papiers est sollicité, seul le contenu volontairement copié puis utilisé par l'utilisateur est traité.

Aucun contrôle VIES n'est déclenché sans action volontaire de l'utilisateur.
